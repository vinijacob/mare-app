## 🇺🇸 English

### About

**Maré** ("tide" in Portuguese) is a mood journal app for iOS, because moods come and go like the tide. Every day you pick how you feel, add an optional note, and later look back at your history and simple statistics.

This is also a **learning project**: the main goals are to practice **SwiftUI**, **SwiftData relationships**, and working with **`Date`**. There is no backend yet. Everything is stored locally on the device.

### Features

- [ ] Pick your mood of the day: 😄 😐 😔
- [ ] Add a note to each entry
- [ ] History organized by date
- [ ] Simple statistics (mood counts, streaks, most common mood)
- [ ] Tags/activities linked to entries (SwiftData relationship)

### Tech stack

- **Swift**
- **SwiftUI**: declarative UI
- **SwiftData**: local persistence and relationships
- **Swift Charts**: statistics (planned)
- **Xcode 16+** / **iOS 17+** (SwiftData requirement)

### Getting started

```bash
git clone https://github.com/<your-username>/Mare.git
cd Mare
open Mare.xcodeproj
```

Then choose a simulator (iOS 17+) and press **Run** (⌘R).

## 🇧🇷 Português

### Sobre

**Maré** é um app de diário de humor para iOS, porque o humor vai e vem como a maré. Todo dia você escolhe como está se sentindo, adiciona uma nota opcional e depois consulta seu histórico e estatísticas simples.

Este também é um **projeto de aprendizado**: os principais objetivos são praticar **SwiftUI**, **relacionamentos no SwiftData** e o uso de **`Date`**. Ainda não há backend, tudo fica salvo localmente no dispositivo.

### Funcionalidades

- [ ] Escolher o humor do dia: 😄 😐 😔
- [ ] Adicionar uma nota a cada registro
- [ ] Histórico organizado por data
- [ ] Estatísticas simples (contagem por humor, sequência de dias, humor mais comum)
- [ ] Tags/atividades ligadas aos registros (relacionamento no SwiftData)

### Tecnologias

- **Swift**
- **SwiftUI**: interface declarativa
- **SwiftData**: persistência local e relacionamentos
- **Swift Charts**: estatísticas (planejado)
- **Xcode 16+** / **iOS 17+** (requisito do SwiftData)

### Como rodar

```bash

open Mare.xcodeproj
```

Depois escolha um simulador (iOS 17+) e aperte **Run** (⌘R).
